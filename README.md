# 🎁 Landing Page B2B — Brindes Corporativos Personalizados

Esta é uma landing page voltada para o mercado **B2B (Business to Business)** de brindes e presentes corporativos. O projeto foi desenhado especificamente para destacar técnicas de personalização avançadas (Impressão UV Digital, Serigrafia/Silk-Screen, Gravação a Laser e Sublimação) e facilitar o fluxo de orçamentos diretamente via WhatsApp.
